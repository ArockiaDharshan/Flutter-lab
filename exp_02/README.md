## Getting Started

### Prerequisites
- Flutter SDK installed (`>=3.0.0`)
- Google Chrome (for web testing) or Android Studio / Emulator

### Run the App
```bash
# 1. Install dependencies
flutter pub get

# 2. Run on Chrome
flutter run -d chrome

# Or run on connected device
flutter run
```
