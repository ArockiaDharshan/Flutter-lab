## 🛠️ Tech Stack & Prerequisites

- **Language:** Dart 3
- **Framework:** Flutter (Material 3)
- **Local Storage:** SQLite (`sqflite`, `sqflite_common_ffi_web`)
- **Cloud Backend:** Google Firebase (`firebase_core`, `cloud_firestore`)
- **Cryptography:** `crypto` (SHA-256 & secure salt)

## 🚀 Running Any Experiment

Navigate into any experiment directory and launch the application:

```bash
# Navigate to the chosen experiment
cd exp_01

# Fetch project dependencies
flutter pub get

# Run on Google Chrome
flutter run -d chrome

# Or run on an Android device / emulator
flutter run
```
